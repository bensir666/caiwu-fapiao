供应商发票跟踪 · 操作手册

适用于跟单员、财务和管理员。手机和电脑上的操作一样。

1. 这个系统是做什么的

系统记录每个供应商应该给我们开多少发票、已经开了多少、还欠多少，电商和工厂两个板块分开算。

  • 应开票额：系统启用前的期初欠票，加上财务终审通过的对账单和调整单（都按含税金额计）。
  • 已开票额：已经入账的发票，按价税合计累加。普票也算；红字发票是负数，会自动冲减。
  • 欠票：应开票额减去已开票额。为负数时，表示供应商多开了。
一句话记住：对账单决定「该开多少」，发票决定「开了多少」，两者一减就是欠多少。

2. 角色和权限

跟单员

  • 只看到分配给自己的供应商
  • 创建、复核、提交对账单
  • 上传供应商发来的发票
  • 查看欠票和催票话术

财务

  • 看所有供应商
  • 终审或驳回对账单
  • 处理「待处理」发票，改发票板块
  • 登记税费成本
  • 维护基础资料，导出报表，查看操作记录

管理员

  • 财务能做的都能做
  • 新建、停用用户，重置密码，强制下线
  • 设置公司名称和启用日

4. 第一次使用

管理员按下面的顺序做一遍，系统就能用了。管理员和财务登录后，首页的「上手引导」会自动打勾，提示还差哪一步，点「去完成」直接跳到对应页面。

另外，每个页面顶部都有一块「这个页面怎么用」的简短提示，看熟了可以点「收起」；页面右上角的「帮助」随时打开这本手册。

  1. 登录并改密码。用部署时拿到的 admin 账号登录，系统会要求先改成你自己的密码。
  2. 系统设置。在「用户与设置」里填写公司名称和启用日。期初欠票按启用日计算账龄。
  3. 登记我方受票主体。在「基础资料 → 我方受票主体」里，把电商和工厂所有收票公司的全称、税号都登记上，并选好板块。最关键发票是按购买方税号判断板块的，没登记的公司开来的票都会进「待处理」。
  4. 录入供应商和开票主体。推荐用「基础资料 → 批量导入」：下载「供应商资料模板」，一行填一个开票主体（同一个供应商有几个开票公司就写几行），填好上传。系统会先预检，确认没问题再导入。也可以在页面上逐个新增。
  5. 核对期初欠票。在「基础资料 → 期初欠票」里，按供应商分电商、工厂填写启用日之前的欠票总额（含税）。
  6. 建账号。在「用户与设置」里给跟单员和财务建账号，并把供应商分配给对应的跟单员（在供应商资料里选「跟单员」）。新账号第一次登录时必须改密码。

5. 日常工作清单

谁什么时候做什么
跟单员和供应商对完账「对账单 → 新建对账单」，或者导入供应商填好的 Excel，核对无误后点「复核无误，提交终审」
跟单员对账单被驳回首页和「对账单」上会有红色数字提醒，看驳回原因，修改后重新提交
跟单员 / 财务收到供应商的发票「发票 → 上传发票」，可以一次选多张，逐张核对后确认
跟单员每周看「催票」，把话术复制发给欠票的供应商
财务每天处理「对账单」里待终审的单据，以及「发票 → 待处理」里的发票
财务每天看「税费成本」里的待登记提醒，登记要另付的税费
财务月底在「欠票总览」里导出 Excel（含账龄），按账龄跟进 60 天以上的欠票

6. 功能说明

欠票总览（首页）

  • 顶部四个数字：应开票额、已开票额、欠票额，以及需要你处理的事项（点击可以直接跳过去）。
  • 欠票账龄：把欠票按时间分成 0–30、31–60、61–90、90 天以上四段，算法见第 7 节。
  • 供应商欠票表：按欠票从多到少排列，进度条表示已开的比例；状态栏显示最早一笔欠了多少天，超过 90 天会标红。点某一行可以看这个供应商的明细。
  • 页面顶部的「全部 / 电商 / 工厂」可以切换板块，所有页面都会跟着变。
  • 跟单员只看得到自己负责的供应商。

供应商明细

按板块分别显示应开（含期初）、已开、欠票和账龄，下面依次列出：

  • 催票话术，可以一键复制；
  • 这个供应商的全部开票主体；
  • 所有对账单和调整单；
  • 所有发票，可以点「原件」查看；
  • 税费成本（只有财务和管理员能看到）。

对账单

新建对账单：

  1. 点「新建对账单」，选供应商和板块。税率会自动带出供应商的默认税率。
  2. 填写期间、金额口径（含税或不含税）和对账金额。下方会实时显示不含税金额、税额和计入应开的含税金额。
  3. 如果这次要另付税费，可以把金额填在「另付税费成本」里备查。实际支付的税费请到「税费成本」里登记。
  4. 核对无误点「复核无误，提交终审」；没想好就先「存为草稿」。

导入供应商填的 Excel：点「导入供应商填的 Excel」，选择供应商按《供应商对账单模板》填好的文件。系统会读出供应商、板块、期间、口径、税率，并把明细行的数量×单价加总成对账金额，自动填进表单。核对后再提交。模板可以在本页右侧下载。

财务终审：在「待终审」里点「通过」，确认框里会显示供应商、板块和计入金额；有问题就点「驳回」并写明原因，跟单员会看到。

调整单：在已生效的对账单那一行点「调整单」，金额填正数表示补差，填负数表示冲减。调整单同样要提交和终审。

发票

上传：在「发票 → 上传发票」里选择文件，可以一次选多张，也可以把文件拖进框里。

  • XML：数电发票的 XML 文件识别最准，能从税务平台或开票方那里拿到时优先用它。
  • PDF：数电发票的 PDF 也能自动识别。
  • OFD、照片：暂时不能自动识别，需要对照原件手工填写，原件同样会存档。
  • 没有文件时，可以点「手工录入」直接填写。

核对：每张发票读出来后，右侧显示识别结果和「归属判断」，说明系统为什么归到某个供应商和板块。请对照原件看一遍号码和金额，然后点「确认提交」。改了某个字段，归属判断会马上重新计算。

红字发票：金额为负数的发票会冲减已开票额，系统还会从备注里找出被冲红的蓝字发票号码。

全部发票（财务）：可以按状态筛选，按发票号或销售方搜索，查看原件。另外有三个操作：

  • 改板块：跨板块核销时用，例如工厂的票冲电商的欠票。
  • 修改：改正识别错的字段。
  • 删除：只在录错时用，删除会留下记录。

待处理发票（财务）

原因通常怎么处理
开票主体未登记选择它属于哪个供应商和板块，勾上「同时登记这个开票主体」，点「分配并入账」。以后这家公司开的票就会自动归属。
共用主体需分配一个开票主体同时属于几个供应商，系统列出候选供应商和各自的欠票，选一个分配。
购买方不是我方先确认是不是漏登了我方的受票主体：漏登了就去「基础资料」补上，再回来分配；确实开错了抬头，就点「退回供应商」。
金额需核对点「修改信息」对照原件改正金额后再分配；原件本身有错就退回。

催票

列出所有还欠票的供应商，每家都配好一段话术，例如：「××您好，截至 2026-11-04，贵司在我司工厂板块还有 4,824.44 元发票未开……」。可以单条复制，也可以全部复制。用「欠票不少于」可以过滤掉金额很小的。

税费成本（财务）

  • 部分供应商开票时，我方要另外支付税费。这部分单独记成本，不影响欠票。
  • 在供应商资料里勾选「开票时我方需要另付税费成本」后，这家供应商的发票一入账，「待登记」里就会出现提醒。
  • 点「登记税费」，填写金额和支付日期即可。确实不需要支付的，点「这张不需要」。
  • 底部明细可以导出 Excel，导出文件里有按供应商汇总的工作表。

基础资料（财务、管理员）

页签内容注意
供应商名称、供应板块、默认税率、是否另付税费、跟单员、联系方式停用的供应商不再出现在下拉框里，但仍有欠票的照常显示
开票主体供应商开票用的公司全称和税号，可以关联多个供应商同一个供应商有多家开票公司时，都挂在它下面，例如京东旗下的几家公司
我方受票主体我方收票公司的全称、税号、所属板块决定发票归电商还是工厂，一定要登记全
期初欠票启用日之前的历史欠票，按供应商分电商和工厂填写含税金额；改完点「保存」
批量导入方式一：供应商资料模板；方式二：供应商填好的对账单模板里的「开票主体」表先预检、后导入；以「示例」开头的行会被跳过

用户与设置（管理员）

  • 新建用户：填姓名、登录用户名和角色，点「随机生成」得到一个合规的初始密码，把用户名和密码告诉对方。对方第一次登录时必须改密码。
  • 用户列表：显示最近登录时间和 IP、在线设备数、是否锁定、是否还没改初始密码。
  • 点某个用户可以：
    • 改姓名和角色；
    • 重置密码，对方会立刻下线，下次登录要改密码；
    • 停用账号，对方会立刻下线；
    • 强制下线并解除锁定。
  • 系统设置：公司名称会显示在页面顶部和催票话术里；启用日是期初欠票的日期，用来算账龄。

账号安全（所有人）

  • 点页面右上角的「账号安全」可以修改密码。密码规则：至少 8 位，同时包含字母和数字，不能包含用户名，不能是常见密码。
  • 改密码后，你在其他设备上的登录会全部退出。
  • 「登录中的设备」列出你在哪些手机或电脑上登录着。看到不认识的设备，先点「退出其他设备」，再改密码。
  • 12 小时不操作会自动退出；一次登录最长保持 7 天。
  • 连续输错 10 次密码，账号会锁定 15 分钟。着急的话可以找管理员解锁。

操作记录（财务、管理员）

系统会记录每一次操作：

  • 创建、修改、提交、终审、驳回、作废；
  • 上传、入账、分配、退回、删除；
  • 登录、登录失败、账号锁定；
  • 导入、改设置。

可以按对象筛选，点「查看」能看到当时提交的具体内容。

导出 Excel

  • 欠票总览（首页右上角「导出 Excel」）：按当前板块导出每个供应商的期初、应开、已开、欠票、四段账龄和最早欠票天数，最后一行是合计。
  • 发票明细（「全部发票」页）：按当前板块和状态筛选后导出。
  • 税费成本（「税费成本」页）：导出明细和按供应商的汇总。

7. 欠票和账龄怎么算

系统采用先开先抵：供应商开来的发票，先冲最早的应开金额，所以还没开票的部分一定是最近的那几笔。每一笔的账龄从这几个日期算起：

  • 对账单：财务终审通过那天；
  • 期初欠票：系统设置里的启用日。
注意：欠票为负数（多开）时，账龄全部为 0。跨板块核销时，财务把发票「改板块」到欠票的那个板块即可。

8. 常见问题

上传 PDF 后有些字段是空的？

多半是扫描件或图片转成的 PDF，里面没有文字层。请对照原件手工补全；能拿到 XML 的话，优先上传 XML。

提示「发票已经录入过」？

发票号码全系统唯一，同一张发票不能入账两次。如果是之前录错了，请财务在「全部发票」里修改或删除那一条。

对账单终审后发现金额错了？

已生效的单据不能修改，请新建调整单，多计了就填负数冲减，少计了就填正数补差。

跟单员看不到某个供应商？

跟单员只能看到分配给自己的供应商。请财务或管理员在「基础资料 → 供应商」里，把这家供应商的「跟单员」改成他。

供应商的发票开到了另一个板块的公司？

如果这家供应商只在一个板块供货，系统会自动改归，并标记「跨板块」。如果它两个板块都供货，财务可以在「全部发票」里点「改板块」。

忘记密码或账号被锁？

请管理员在「用户与设置」里点你的名字，重置密码或者「强制下线并解锁」。

手机上怎么用？

用手机浏览器或微信打开系统地址就行，功能和电脑上一样，表格会自动变成卡片显示。上传发票时可以直接选择手机里的 PDF 或 XML 文件。
